# Анализ API для получения данных о котировках акций

## Результаты тестирования

Ниже представлены результаты тестирования различных API для получения данных по акциям на примере тикера OZON:

### 1. Tinkoff Invest API

**Статус**: ✅ Успешно

**Данные**:
```json
{
  "figi": "BBG00Y91R9T3",
  "price": 3767.5,
  "time": "2025-04-25 09:17:04.102156+00:00"
}
```

**Преимущества**:
- Прямой доступ к российскому рынку
- Детальная информация по инструментам
- Доступ к стакану заявок
- Высокая скорость обновления

**Недостатки**:
- Требуется API-ключ (токен)
- Ограничен в основном российским рынком

### 2. Yahoo Finance

**Статус**: ❌ Не работает для OZON

**Данные**: OZON не найден (возможно, прекращен листинг)

**Преимущества**:
- Глобальный охват рынков
- Не требует API-ключа (базовое использование)
- Исторические данные

**Недостатки**:
- Ограниченная скорость запросов
- Нет надежного доступа к российским акциям

### 3. MOEX ISS API

**Статус**: ⚠️ Работает частично

**Данные**: Возникли проблемы с получением данных в текущей реализации

**Преимущества**:
- Официальный API Московской биржи
- Подробная информация по российским акциям
- Не требует API-ключа

**Недостатки**:
- Сложная структура данных
- Требует дополнительной обработки

### 4. Alpha Vantage

- Богатый набор финансовых данных

**Недостатки**:
- Требуется API-ключ
- Ограничение на количество запросов (бесплатный план)

### 5. Finnhub

## Выводы и рекомендации

### Рекомендуемые API для использования

1. **Tinkoff Invest API** - лучший выбор для российского рынка, включая OZON
   - Надежность и скорость работы
   - Детальные данные по инструментам
   - Официальное API с документацией

2. **MOEX ISS API** - требует доработки, но может быть полезным дополнением
   - Официальный источник данных с Московской биржи
   - Не требует API-ключа

### Источники, требующие API-ключей

Для расширения охвата глобальных рынков рекомендуется получить API-ключи для:
- Alpha Vantage
- Finnhub

### Примечания

1. Для получения данных по российским акциям надежнее всего использовать Tinkoff Invest API
2. Для парсинга данных с веб-сайтов (РБК, Investing.com) требуется более надежное решение
3. Yahoo Finance работает нестабильно для российских акций
